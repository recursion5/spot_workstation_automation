# ADR 0008 — Internal NOTICE, no public license

- Status: accepted
- Date: 2026-08-19

## Context

The constitution asked for `LICENSE-or-NOTICE-as-appropriate`. This is an internal operations repo.

## Decision

Ship `NOTICE` stating the project is not licensed for public use. Do not add MIT/Apache unless the owner asks.

## Alternatives considered

- MIT — would invite redistribution of operational detail.

## Consequences

Third-party tools added later still need their own licenses recorded.
