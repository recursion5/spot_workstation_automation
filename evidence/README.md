# Evidence

Raw discovery bundles do **not** belong in git.

On the controller, store runs under `$SPOT_EVIDENCE_ROOT` (default `/home/grok-agent/spot-discovery/evidence/<run-id>/`).

This directory may hold:

- pointer markdown files generated by `spotctl.py package-evidence`
- checksums of tiny sanitized samples

Never place `.pml`, `.etl`, `.evtx`, memory dumps, ICA bodies, or credential files here in a form that git will track. `.gitignore` blocks the common patterns; do not force-add them.
